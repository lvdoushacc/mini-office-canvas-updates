## 它是什么

小小办公是一个运行在你电脑上的 AI 创作画布。你在画布上放下提示词、参考图、视频和音频卡片，用连线把它们串起来，再选一个模型点生成，结果会直接落在画布上，接着还能继续拿去做下一步。

没有账号，没有订阅。你填上自己的 API Key，生成的内容和画布都只保存在自己的电脑里。

## 主要功能

**画布创作**
- 无限画布，节点卡片可拖动、连线、批量排列；大画布也能流畅缩放。
- 文字、图片、视频、音频节点；生成的素材自动命名为「图片1」「视频1」……
- 图片编辑器：裁剪、宫格切分与拼合。
- 提示词润色：当前模型没开通时，会自动换成同平台可用的文本模型重试。

**接入模型（自带 API）**
- 内置多种协议：OpenAI V1、MiniMax（海螺）V2、火山引擎 V3、APIMart 异步协议。
- 支持 Gemini、OpenAI 命令行工具方式调用。
- 在「设置」里填 Key、测试连通，随时切换平台。

**多人协作**
- 局域网内实时协作：看得到对方光标，一起编辑同一张画布。
- 加入协作后直接进入协作画布，昵称自动带入。

**安全与省心**
- 每天自动备份画布，保留最近 7 天，主页一键恢复。
- 删除的画布和素材先进回收站。
- 本机服务带跨站请求防护，API Key 保存在本地数据目录，不会被打进安装包。
- 界面为 iOS 风格，支持深色模式、多种主题色，可选 28px 圆角或 Windows 原生窗口外框。

## 下载与安装

1. 打开 [Releases](../../releases/latest) 页面。
2. 下载 `MiniOffice-Setup-vX.Y.Z.exe`，双击安装即可。
3. 第一次打开后，进入「设置」，填入你自己的 API Key。

> 已经装过旧版？可以下载同一页面里的 `MiniOffice-Patch-vX.Y.Z.zip` 轻量补丁，体积小，更新更快。

**系统要求**：Windows 10 / 11，64 位。

## 技术简介

- 前端：原生 HTML / CSS / JavaScript，画布由 50+ 个功能模块组成
- 后端：Python + FastAPI 本地服务，数据以文件形式保存在本机
- 桌面外壳：Electron，透明圆角窗口
- 视频处理：内置 ffmpeg
- 打包：Inno Setup 安装包 + 增量补丁
